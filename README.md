# Vanya 数字大脑 · 公开分享版

把 Vanya 的业务判断、产品转化、交付统筹与 AI 落地方法整理成可安装的 Skill。适合项目负责人、产品与运营伙伴、小团队及实际推进 AI 应用的人。

技能名：`vanya-brain-public`。公开版本：`v1.0.0`。

## 它能帮你做什么

- 找业务链路里最影响结果的断点。
- 从用户需求、价值感知与交付成本设计产品。
- 设计直播与私域承接、交付责任和复盘。
- 判断 AI 开发的范围与验证顺序。
- 用直接、具体、有业务判断的方式表达。

公开版仅包含方法与假设示例，不包含客户成绩、个人经营数字、原始资料或私人路径。

## 在 Codex 中安装

打开 [最新发布](https://github.com/EnterBoom/vanya-brain-public/releases/latest)，下载 `vanya-brain-public-v1.0.0.zip`。

把ZIP附到Codex聊天里，发送：“帮我安装这个Skill”。安装后在下一条消息调用：

```text
使用 $vanya-brain-public，帮我判断这个项目最主要的瓶颈，并给出下一步动作和完成标准。
```

也可让Codex从本仓库的 `vanya-brain-public` 目录安装。手动安装时将这个目录放到Codex用户技能目录，保持 `SKILL.md` 位于技能目录第一层。

其他兼容Skill的环境按其导入方式安装。普通ChatGPT对话不能把这个ZIP当可运行插件；可读取文件作为方法参考，但不因此获得本机文件访问能力。

## 示例提问

```text
使用 $vanya-brain-public，这个产品用户为什么买、我们能不能交付、先验证什么？
使用 $vanya-brain-public，有咨询没成交，帮我拆断点，不要先给流量建议。
使用 $vanya-brain-public，把这次交付复盘成结果、责任、证据和下一期改进。

使用 $vanya-brain-public，帮我把这个判断写成口播，不编造我的经历。
```

## 使用与版本

这是Vanya的方法分享版，不是你的个人大脑。它不会把作者经历赋给你，也不连接作者私人知识库。你可以用自己的真实背景提问；个人资料应留在你授权的环境中。

私人版与公开版使用不同技能名，可同时存在。今后更新通过新的GitHub版本发布，安装者自行升级。
